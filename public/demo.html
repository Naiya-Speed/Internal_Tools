Speed Internal Tools  ·  The Problem

What we were
doing manually

Every step below was done by hand — every single time.

✗ Before — Manual
  • 📊Fee calculations done in spreadsheets — different formula for inclusive vs exclusive, easy to mix up
  • 🔁GreenDot deposits required 3 separate API calls manually — login → create deposit → SOAP auth → complete
  • 🔑JWT tokens expire every 15 min — had to re-login constantly to get fresh tokens for each operation
  • ⚠️No single place for the team — each person maintained their own scripts or spreadsheets
✓ After — Automated
  • ✓Fee calculator handles both modes instantly — just enter amount and rates, all breakdowns computed
  • ✓GreenDot full flow runs in one click — login, deposit, barcode, SOAP, complete — all chained automatically
  • ✓Token management is handled server-side — team never touches auth headers
  • ✓Single URL, login protected — one tool the entire team uses
